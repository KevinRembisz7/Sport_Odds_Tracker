# 🎯 Sport Odds Tracker

_Made by Kevin Rembisz & William Mah_

**Live site → https://kevinrembisz7.github.io/Sport_Odds_Tracker/parlay-maker/**

Daily +EV sports picks, player props and parlays. Every price is checked against the sharp no-vig line and backed by injuries, hit rates and matchup stats. It rebuilds itself every morning via GitHub Actions and publishes to GitHub Pages.

- ⭐ **Pick of the Day** and 🎯 **Parlay of the Day**, picked for being the most likely to hit while still +EV.
- 📈 **Track record**: every pick is auto-graded from the final box scores the next morning.
- 📋 **bet365 sheet**: the fair odds and a target price for every line and prop. Type in bet365's price to see your edge.

Details, setup and the credit budget are in [`parlay-maker/README.md`](parlay-maker/README.md).
